# Akeda Marketplace for Codex

Официальный Marketplace-репозиторий плагина **Akeda ERP** для Codex и ChatGPT.

Плагин добавляет Akeda ERP в список плагинов с фирменной иконкой, описанием и
стартовыми сценариями. После установки пользователь входит в Akeda через OAuth
и работает только в пределах своей роли, доступных кабинетов и прав.

Этот репозиторий намеренно не содержит исходный код ERP, данные клиентов,
токены или ключи. Он публикует только каталог Marketplace, бренд-материалы,
инструкции для агента и адрес защищённого MCP-сервера.

## Установка

1. В Codex откройте **Plugins** и выберите **Add marketplace**.
2. Укажите GitHub-репозиторий `Artogceo/akeda-codex-marketplace`.
3. Откройте источник **Akeda Marketplace** и установите **Akeda ERP**.
4. После установки выберите **Authenticate** и войдите в Akeda под своей
   учётной записью.

При первом запросе Codex может спросить, в каком кабинете работать. Это
нормально: кабинет — рабочее пространство клиента, а не юридическое лицо.

## Что умеет плагин

- задачи, проекты, документы, встречи, файлы и связи с ERP-сущностями;
- справочники, товары, контакты и документы;
- склад и остатки;
- финансы, операции, сверка и отчёты;
- календарь и занятость;
- данные Ozon, Wildberries и Яндекс Маркета;
- производственный контур Recom, если он включён для кабинета.

Набор фактически доступных действий всегда определяется ролью пользователя в
Akeda. Сервер доступен по `https://erp.akeda.ru/mcp` и использует OAuth 2.1;
ни API-ключ, ни локальный сервер не требуются.

## Обновления

Codex получает обновления Marketplace из этого репозитория. Функции ERP и
авторизация обновляются на стороне Akeda, поэтому пользователю не нужно
переустанавливать плагин для каждого серверного обновления.

Если меняется MCP tool surface или server-card версия, версия Marketplace-плагина
в `plugins/akeda-erp/.codex-plugin/plugin.json` тоже поднимается. Так Codex не
держит устаревший индекс инструментов для уже установленного плагина.

## Разработка

Структура соответствует формату плагинов Codex:

```text
.agents/plugins/marketplace.json  # каталог, который добавляет пользователь
plugins/akeda-erp/                # устанавливаемый плагин
├── .codex-plugin/plugin.json     # карточка, бренд и компоненты
├── .mcp.json                     # OAuth MCP Akeda
├── assets/                       # иконка и логотип
└── skills/akeda-erp/SKILL.md     # правила и сценарии работы агента
```

Публикация исходного кода этого Marketplace-репозитория не открывает доступ к
ERP. Доступ к данным проверяется только после OAuth-входа на стороне Akeda.
